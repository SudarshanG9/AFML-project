# Historical frozen experiment tools

The Day C paths identify accepted preparation, validation, freeze, execution and recovery records. Keep them unchanged. For everyday cached-feature validation use the Member 3 runtime CLI instead.

`preflight.py`, `build_colab_pilot_package.py` and `colab_query_pilot.py` establish the approved pilot environment and query intervention. `run_day8.py` and the Day 8 Colab/evaluation wrappers produce or inspect matched validation evidence. `freeze_day9.py` records the scientific policy. `build_day10_package.py`, `colab_day10.py`, `run_day10_test.py`, `audit_day10.py` and `package_day10_handoff.py` preserve the authorized held-out chain. `recovery_day10.py` and `additional_recovery_day10.py` implement explicit recovery rather than silent retry. `recovery_inventory.py` and `restore_verified_inputs.py` inspect or restore approved inputs. Member handoff completion/review tools preserve acknowledgement and source identities.

These are reproducibility utilities, not a checklist to rerun the accepted test. Some require private original archives. Their names, source bytes and configuration paths are part of inventories; descriptive replacements would break that lineage.
